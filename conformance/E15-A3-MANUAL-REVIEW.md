# E15-A3 manual boundary review

Status: complete.

The review confirms that E15-A3 owns external publication records, bounded persistence observations, independent readback records and their derived lifecycle decisions as separate authorities.

It confirms the following non-equivalences:

```text
publication record != public accessibility
publication acceptance != bounded persistence
bounded persistence observation != indefinite durability
independent process != independent provider
readback digest match != semantic truth
readback failure != global absence
```

The registry is structural-only. It contains no live publication credential, production locator, payload or external account identity.

Known negative evidence precedes contested, unavailable and held outcomes. Missing or inaccessible observations are not converted into positive publication, global absence or durability claims.

E15-A3 does not own withdrawal, tombstones, distribution stops, erasure, legal recall or the final independent external-evidence verifier matrix. Those remain reserved for E15-A4 and E15-A5.

The current-tree A2 unit harness now reconstructs its own frozen A2 profile instead of inheriting the descendant A3 profile. This is a test-fixture isolation correction only; exact A2 semantics remain replayed from source commit `25988d80571f0f8d3587d976810a2dd8e0ce2328`.
