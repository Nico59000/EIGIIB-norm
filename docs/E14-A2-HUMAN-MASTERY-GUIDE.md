# E14-A2 human mastery guide

## Operational question

Before any disclosure action, answer in this order:

1. Which sealed projection is being considered?
2. Which exact audience revision is eligible?
3. Which exact policy revision permits the projection?
4. Which exact context revision still matches the purpose, action, operation and subject?
5. What derived decision follows?

Do not start from a desired `permit` label and search backward for supporting identifiers.

## Four independent gates

| Gate | Positive state | What it does not prove |
|---|---|---|
| projection | admissible | disclosure permission |
| audience | eligible | audience authentication |
| policy | permit | policy authority outside this registry |
| context | admissible | trusted wall-clock freshness |

A final permit exists only when all four gates are positive.

## Revision discipline

A change to the audience, policy, context, projection or source commitment invalidates the old request boundary. Create a new request; do not edit the old decision in place.

## Negative precedence

A direct negative result is not softened by an unavailable or held input. Otherwise, unavailable precedes held. This prevents a known denial from being hidden behind an operational uncertainty.

## Human review prompts

- Is the projection sealed rather than merely prepared?
- Does the audience explicitly include the source subject, classification and purpose?
- Does the policy admit every projected claim type and predicate?
- Is each assurance value below the policy ceiling?
- Are all required correlation-control identifiers present?
- Does the context still match the exact operation?
- Are permit/deny evidence identifiers material and reviewable?

## Boundary sentence

A conformant E14-A2 permit authorizes only the registry-defined crossing. It does not authenticate the recipient and does not release or transmit the projection.
