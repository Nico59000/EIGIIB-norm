# P1-A7.3 — Identity/Projection Adapters, Multi-Defect Precedence and Remaining Structural Replay

P1-A7.3 is an additive structural closure within P1-A7. It preserves the P1-A7.1 generator corpus and the P1-A7.2 route adapters byte-for-byte, then introduces a separate structural seed, corpus and adapter set for identity, projection and precedence obligations.

## Structural adapter order

Every P1-A7.3 adapter evaluates the same closed boundaries in this order:

```text
UTF-8
JSON syntax and duplicate members
canonical base64
portable repository-relative path
declared byte length
declared SHA-256 digest
closed seven-field projection
```

The first failing boundary supplies the portable class. Later defects remain present in the input but cannot replace an earlier class.

## Additive seed and corpus

P1-A7.3 uses:

```text

tests/fixtures/p1-a7/a7.3-structural-corpus.json
```

The seed binds the decoded base64 payload by observed byte length and SHA-256 digest. Its projection contains exactly the seven P1-A5 fields and the closed chain identity.

The corpus contains nine negative vectors:

```text

```

The first eight close each structural family individually. The ninth carries four simultaneous defects and declares this precedence:

```text
encoding.noncanonical-base64
path.unsafe
identity.length-mismatch
projection.invalid
```

The required result is the first class because it has the lowest taxonomy rank among the defects present.

## Route implementations

The three structural adapters are:

```text
tools/eigiib_p1_a7_structural_adapter.py
independent/p1structural/adapter.go
external/p1structural/adapter.go
```

Their command entry points are separate from the P1-A7.2 adapters. This prevents a later structural extension from silently revising the exact A7.2 closure.

The external route participates through its pre-COSE structural ingestion boundary. P1-A7.3 does not claim that `go-cose` is invoked for these inputs.

## Identity boundary

The identity carrier must contain exactly:

```text
algorithm
bytes
digest
```

The algorithm must be `sha256`. The length check precedes the digest check. A carrier with both a wrong length and a wrong digest therefore maps to `identity.length-mismatch`.

## Projection boundary

The projection must contain exactly:

```text
manifest_binding_result
p1a1_replay_result
p1a2_replay_result
p1a3_replay_result
cross_capsule_binding_result
end_to_end_result
chain_identity
```

All six result fields must be `conformant`. The chain identity must equal the exact P1-A5 chain identity. Missing, extra or changed fields map to `projection.invalid`.

The orchestrator is:

```text

```

It validates the A7.3 corpus, reproduces each mutation sequence, checks every generated SHA-256 and byte length, builds both Go adapters with `-mod=readonly` and `-trimpath`, and compares all route results with:

```text
tests/fixtures/p1-a7/expected-a7.3-structural-replay.json
```

The canonical report contains:

```text
1 positive input
9 negative inputs
3 routes
30 observations
```

## Closure boundary

P1-A7.3 closes the structural JSON, UTF-8, base64, path, identity and projection families, including one declared multi-defect precedence vector. It does not close manifest membership, DSSE, signatures, deterministic CBOR, COSE headers or structure, Receipt proofs, production-input coverage, universal parser equivalence or reproducible toolchain identity.
