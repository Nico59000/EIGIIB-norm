# IDP-A5 Human Mastery Guide

Use A5 only after the A4 public projection is already structurally conformant.

1. Recompute the exact source and projection digests.
2. Require the projection to be byte-identical to the reviewed A4 source.
3. Bind every review to that exact projection digest.
4. Count at most one decision per declared independent authority.
5. Require the declared two-of-three approval threshold.
6. Freeze only after all counted approvals.
7. Keep `publicationAuthorized` false in the structural corpus.

A5 does not grant production publication authority. A real deployment must register real reviewer identities, key custody, release authority, publication endpoints, and operational evidence in a later slice.
