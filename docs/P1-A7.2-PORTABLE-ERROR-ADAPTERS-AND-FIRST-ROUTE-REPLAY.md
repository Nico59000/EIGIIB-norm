# P1-A7.2 — Portable Error Adapters and First Route-Bound Replay

P1-A7.2 binds the first five structural vectors to all three required routes. The scope stops after portable path validation and therefore precedes identity, projection, DSSE, CBOR, COSE and Receipt processing.

## Route adapters

```text

```

Each adapter emits the same closed carrier:

```text

```

The carrier schema is `schemas/eigiib-p1-a7-portable-route-result.schema.json`. Human-readable diagnostics, exception text and parser internals are excluded from equality.

## Ordered validation boundaries

The first-slice adapters evaluate boundaries in this order:

```text
UTF-8
JSON syntax and duplicate members
canonical base64
portable repository-relative path
```

This order is declared policy rather than incidental parser order. A failure terminates evaluation at its first authoritative boundary.

## Closure condition

P1-A7.2 is conformant only when:

- the positive seed is accepted by all three routes;
- all five negative vectors are rejected by all three routes;
- each vector maps to one identical portable class on all routes;
- every emitted carrier matches the closed format;
- the complete report equals the checked-in canonical result;
- Ubuntu, macOS and Windows produce the same report;
- P1-A5 and P1-A6 remain conformant.
