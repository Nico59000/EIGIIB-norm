# M0-A11 human mastery guide

M0-A11 builds the measuring instruments before the external experiment begins.

The registry asks **who controls each part**. A different service name is not enough: account, identity root, administrators, billing, credentials, runner and logs must be compared.

The channel bootstrap asks **what must be proven after storage exists**. A retention setting is only intent until the provider returns a locked policy, an immutable object version and failed deletion attempts.

The observation campaign asks **who checked, what they checked and when the next check is due**. Every observation is numbered and chained to the previous digest. Missing time is evidence of a lapse, not an empty success.
