# EIGIIB standard package

This directory is a repository-ready seed for a future standalone EIGIIB project.

- `EIGIIB-STANDARD.md` is the canonical normative specification.
- `eigiib-conformance.schema.json` is an optional machine-readable audit record schema.
- `EIGIIB-PROFILE.example.yaml` shows how downstream projects can adopt the standard without copying it.

The package intentionally keeps the normative content in one document. The schema and profile example exist only because machine-readable conformance and downstream adoption have different authority roles.
